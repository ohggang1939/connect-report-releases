전체 15분 · 프로그램에 그림 가이드가 내장되어 있습니다

자동보고 스케줄 등록과 바로가기 생성이 자동으로 되고, 그림 설치가이드와 관리 화면이 열립니다.

카카오톡 연결

보고를 받을 무료 열쇠를 발급받는 과정입니다. 가이드 그림대로 따라 하면 됩니다 (최초 1회, 약 8분).

네이버 계정 등록 + 보고 시간 설정

네이버 로그인('로그인 상태 유지' 체크!) 후 원하는 보고 시간을 정하면 끝.

컴퓨터만 켜두면 끝! (설정시간에 꺼져있더라도 컴퓨터를 켜면 바로 자동으로 보내줘요!)

PC를 완전히 종료하지 않고 켜두거나 절전(잠자기)으로 두면, 다음 날부터 매일 자동으로 실적 카톡이 도착합니다.

💡 왜 컴퓨터를 켜둬야 하나요? 네이버는 보안 정책상 외부 서버가 회원의 실적 정보를 대신 조회하는 것을 차단합니다. 그래서 실적 확인은 반드시 본인 PC의 본인 로그인으로만 가능하고, 알리미도 본인 PC에서 직접 확인해 보내드리는 방식입니다. 덕분에 로그인 정보가 밖으로 나갈 일도 없습니다.

⚠️ 처음 실행할 때 Windows 파란색 보안 경고가 뜰 수 있습니다. 아직 소규모 무료 프로그램이라 Microsoft 인증서(유료)를 붙이지 않아서 나오는 표준 경고로, "추가 정보 → 실행"을 누르면 됩니다.

자주 묻는 질문

정말 무료인가요?

네, 실적 알리미 기능은 평생 무료입니다.

비밀번호나 개인정보를 가져가지 않나요?

비밀번호는 저장되지 않으며, 계정·실적 정보는 본인 PC 밖으로 나가지 않습니다. 품질 개선을 위한 익명 사용 통계(무작위 설치번호·버전·실행 여부)만 전송됩니다.

PC를 꺼두면 어떻게 되나요?

완전히 종료된 동안은 보고가 오지 않습니다. 절전(잠자기)은 괜찮습니다 — 보고 시간에 자동으로 깨어나 실행되고 다시 잠들어요.

실적은 언제 기준인가요?

전일(어제) 기준입니다. 네이버가 당일 실적을 다음날 오전 6시에 집계하기 때문에, 보고 시간은 오전 6시 이후를 권장합니다.

설치하다 막히면요?

오픈채팅방으로 오세요. 어려운 점이나 개선사항, 원하시는 기능을 알려주시면 적극 반영하겠습니다. 👉 문의 오픈채팅방
